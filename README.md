# Mortgage Calculator
A simple command-line mortgage calculator built using Python.
## Features
    Calculates monthly mortgage payments
    Shows a full amortization breakdown
    Displays total amount paid and  total interest

## How to Use
1. Run the program
    python mortgage_calculator.py
2. Enter your loan details when prompted:
    Loan Amount
    Annual Interest Rate
    Loan term in years

## Example
     Loan Amount: 300000
     Annual Interest Rate: 7.5
     Loan Term: 30

Monthly Payment:  $2,097.64
Total Paid:       $755,151.67
Total Interest:   $455,151.67
